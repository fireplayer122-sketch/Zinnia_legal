# Website image assets

The original Zinnia website used four binary image files here:

- `zinnia_pfp.jpg`
- `hakari.png`
- `yui_magical.png`
- `nagara.png`

The GitHub connector used for this migration can write repository text files but does not directly transfer the old binary image attachments.

The current homepage uses styled card placeholders so the site works without broken images.

When the original artwork is uploaded here later, we can switch the homepage back to the original floating-card artwork.
